# 🕌 Qur'an Memorisation Journey Companion

## 📌 Overview
An AI-powered assistant that helps Muslims memorise 
and retain the Qur'an consistently and effectively.

## 🔥 Problem I Wanted to Solve
Many Muslims struggle to stay consistent with Qur'an
memorisation without a structured system or teacher
available at all times.

## 💡 My Solution
An AI companion that:
- Tracks memorisation progress
- Schedules smart revision reminders
- Provides personalised motivation
- Generates study plans based on your availability

## 🛠️ Built With
- AWS PartyRock
- Generative AI
- Prompt Engineering
