### My Understanding

I learned that machine learning is not just about training a model and making predictions. It is a complete process that starts with identifying a business problem and ends with using a trained model to make useful predictions that can help solve that problem.

The machine learning process can be divided into three major stages: training, model, and prediction. However, these stages contain several smaller steps.

The process begins by clearly identifying the business problem that needs to be solved. We then carry out ML problem framing, where we determine how machine learning can be applied to the problem and what type of learning approach may be appropriate, such as supervised, unsupervised, or reinforcement learning.

After this, we move to data collection or integration, followed by data preparation, where the data is cleaned and made suitable for the machine learning process. We can then perform data visualization and analysis to understand the data better.

One important stage I learned about is feature engineering. This requires creativity and ingenuity because we need to determine which information in the data can help the model perform better and produce more useful results.

The prepared data is then used for model training, where the machine learns patterns from the training dataset and creates a model. The model is then evaluated using a test dataset to determine how accurately it can make predictions on data it has not trained on.

However, model accuracy is not the only thing that matters. We also need to carry out business goal evaluation to determine whether the model is actually helping to solve the original business problem.

Finally, the trained and evaluated model can be used to make predictions.

My Overall Takeaway

My biggest takeaway is that machine learning starts with a business problem and results in a prediction. The model is not the final goal; it is a tool used to solve a real-world problem.

I also learned that good machine learning depends on more than simply choosing an algorithm. Understanding the problem, collecting good data, preparing the data properly, engineering useful features, training and evaluating the model, and ensuring that the final result meets the original business goal are all important parts of the process.
